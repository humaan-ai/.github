## Why we build

We believe developers should have the tools to build robots that learn
and improve through experience.

Our mission is to advance physical intelligence by enabling robots to
learn from the real world. We’re building toward a future where developers
can assemble intelligent robot systems from reusable building blocks.

**Our long-term goal: make physical intelligence composable.**

## Where we’re starting

Learning starts with experience: what a robot observes, the actions it
takes, and the outcomes that follow.

Our first tools help developers work with those experiences:

- **Humaan Studio** — a desktop workspace for inspecting and curating
  robot experiences.
- **Humaan CLI** — terminal tools for managing recordings.

Both run locally, with no cloud account required. They are in early alpha,
and interfaces and data formats may change.

These tools are our starting point toward a continuous learning loop
connecting experience, data curation, training, and evaluation.
